## Short post

I’m bringing my QA background into AppSec and DevSecOps through COMPANY Security Lab—a hands-on project built around one question: how do I prove that a security control works?

The lab connects threat → priority → control → negative test → evidence. It covers cross-user access, protected fields, webhook replay and input limits using a synthetic NestJS API and Python/pytest tests.

A real dependency audit led to compatible updates and repeat testing. Remaining findings stay visible instead of being hidden behind a green dashboard.

My approach is informed by OWASP, NIST, MITRE and current threat reports. This is a learning portfolio supporting my move toward junior/early-mid security roles—not a claim of production ownership or compliance certification.
